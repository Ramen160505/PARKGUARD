# PARKGUARD 🚗

Україномовний Expo / React Native MVP-проєкт помічника з паркування.

## Поточні можливості
- вибір фото дорожнього знака з медіатеки;
- збереження поточних GPS-координат за дозволом користувача;
- локальний таймер на 30, 60 або 120 хвилин;
- локальне збереження стану на пристрої;
- базові unit-тести та GitHub Actions CI.

## Запуск
Потрібен Node.js 20+.

```bash
npm install
npm test
npx expo start
```

## Важливо
Це початковий MVP. Розпізнавання знаків, офіційна база українських ПДР/обмежень, карти, сервер, push-сповіщення та перевірка ризику штрафу ще не реалізовані. Застосунок не гарантує, що паркування дозволене. Перед публікацією потрібні повне тестування на iOS/Android, перевірка правил і політика конфіденційності.
