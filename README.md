# PARKGUARD 🚗

Україномовний Expo / React Native MVP-проєкт помічника з паркування.

## Поточні можливості
- фотографування дорожнього знака камерою або вибір зображення з медіатеки;
- збереження поточних GPS-координат за дозволом користувача;
- відкриття збереженого місця в Google Maps;
- історія до 10 останніх збережених місць із датою та координатами;
- таймер на 30, 60 або 120 хвилин;
- локальне сповіщення про завершення таймера за умови дозволу сповіщень;
- локальне збереження стану на пристрої;
- unit-тести та GitHub Actions CI із перевіркою TypeScript.

## Запуск
Потрібен Node.js 20+.

```bash
npm install
npm test
npm run typecheck
npx expo start
```

## Тестова Android-збірка
Після встановлення EAS CLI та входу в обліковий запис Expo:

```bash
npx eas-cli build --platform android --profile preview
```

Профіль `preview` налаштований для внутрішнього APK. Перша збірка потребує підключеного Expo-акаунта та запуску EAS Build.

## Важливо
Це MVP, а не юридичний сервіс. Автоматичне розпізнавання знаків, перевірка офіційної бази українських ПДР/обмежень, карти всередині застосунку, сервер і перевірка ризику штрафу ще не реалізовані. Сповіщення залежать від дозволів ОС і можуть обмежуватися режимами енергозбереження. Застосунок не гарантує, що паркування дозволене. Перед публікацією потрібні повне тестування на iOS/Android, перевірка правил, політика конфіденційності та перевірка вимог магазинів застосунків.
